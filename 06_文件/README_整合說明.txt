Wu + Project_v2 整合專案｜資料夾整理版
====================================

專案目標
--------
以 Wu V4 作為唯一道路幾何來源，整合 Project_v2 的汽車與機車縱向行駛邏輯，
並支援機車兩段式左轉。道路資料與程式碼分開存放；程式透過專案根目錄定位
道路資料，不再要求 .m 與 .mat 必須位於同一層。

資料夾配置
----------
01_執行入口/
    RUN_WU_PROJECT_V2.m：執行完整汽車＋機車模擬。
    RUN_ROAD_ONLY.m：只顯示道路與號誌，不產生車輛。
    SHOW_MOTORCYCLE_PATHS.m：顯示機車兩段式路線。
    CHECK_PROJECT.m：初始化 MATLAB 路徑並檢查道路資料。

02_模擬核心/
    runWuProjectV2Simulation.m：模擬主程式，包含車流生成、號誌時序、
    汽機車移動、跟車、等待時間與兩段式左轉流程。

03_道路與視覺化/
    showRoadV4.m：繪製道路、待轉格、斑馬線及號誌外觀。
    setRoadLightsV4.m：更新號誌畫面，不負責車輛路權判斷。
    roadPoseV4.m：依 pathId 與距離取得座標、車頭方向。
    drawRoadVehicleV4.m：繪製或更新汽車／機車圖形。

04_道路資料/
    intersectionMap_v3_twoStage_v4.mat：道路、車道、路徑、停止線、
    待轉格與兩段式路徑資料；請勿任意改名或移出此資料夾。
    ROUTE_IDS.csv：路線索引與對照資料。

05_檢查工具/
    checkWuProjectV2Map.m：檢查 30 條路徑分組與 8 組兩段式路徑銜接。

06_文件/
    本文件及 README_給同學.txt。

07_參考圖片/
    專案畫面參考圖。

專案根目錄
----------
getWuProjectRoot.m：回傳專案根目錄。所有需要載入道路資料的程式都透過它
取得根目錄，再使用 fullfile(projectRoot,'04_道路資料',檔名) 組合路徑。
請保留此檔在最外層，不要移入子資料夾。

如何執行
--------
1. 解壓縮整個資料夾，不要只複製單一 .m 或 .mat。
2. MATLAB 開啟 01_執行入口 資料夾中的腳本。
3. 建議先執行 CHECK_PROJECT.m；成功後再執行 RUN_WU_PROJECT_V2.m。
4. 若只想看道路，執行 RUN_ROAD_ONLY.m；要檢查兩段式路線則執行
   SHOW_MOTORCYCLE_PATHS.m。

路徑設計原則
------------
- 入口腳本先以自身位置往上一層取得專案根目錄。
- 入口腳本使用 addpath(genpath(projectRoot))，將專案子資料夾加入 MATLAB
  搜尋路徑，因此模擬核心可以呼叫道路繪圖函式與根目錄 helper。
- 道路資料以專案根目錄為基準，明確指定 04_道路資料 子資料夾。
- 不要只搬動資料夾或改檔名；若未來更名資料夾，必須同步修改所有
  fullfile(...) 路徑。

整合邏輯摘要
------------
1. Wu 的 map.paths 是車輛位置與方向的主要依據。
2. Project_v2 的舊 Node／RoadSegment 座標映射未直接沿用，因其車道偏移
   與舊情境座標和 Wu V4 道路座標不同。
3. 機車第一段依來車方向直行綠燈進入待轉格；抵達後停止並保留 slot。
4. 機車第二段等待垂直方向直行綠燈，不使用汽車左轉箭頭。
5. 第二段離開待轉格後釋出 slot；汽車保護左轉相位保留給汽車使用。
6. 模擬加入黃燈與全紅清空時間；號誌圖形函式本身不會自動控制路權。

檢查結果與限制
--------------
道路 MAT 資料已在整理時進行靜態檢查：
- map.paths 共 30 條：1–14 一般路徑、15–22 機車第一段、
  23–30 機車第二段。
- 8 組第一段終點與第二段起點距離皆為 0，且 waitBox 與 slot 相符。
- 此檢查是資料結構靜態檢查，不等同已在 MATLAB 執行完整動畫。
- 本次環境未執行 MATLAB，因此仍請在 MATLAB 先跑 CHECK_PROJECT.m，
  再跑模擬入口，確認當地 MATLAB 版本與工具箱相容性。
