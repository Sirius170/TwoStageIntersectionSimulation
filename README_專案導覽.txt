Wu_Project_v2｜專案資料夾導覽
==============================

第一次使用請先看：06_文件/README_整合說明.txt

資料夾用途：
01_執行入口    可直接按 Run 的入口腳本
02_模擬核心    汽車、機車與號誌模擬主程式
03_道路與視覺化 道路、號誌、車輛繪圖及座標函式
04_道路資料    .mat 道路地圖與 .csv 路線索引
05_檢查工具    道路資料與兩段式路線檢查
06_文件        專案設計、執行方式與組員交接文件
07_參考圖片    專案畫面參考圖

專案根目錄的 getWuProjectRoot.m 是路徑定位工具，請勿移動。

建議執行順序：
1. 01_執行入口/CHECK_PROJECT.m
2. 01_執行入口/RUN_WU_PROJECT_V2.m

只看道路：01_執行入口/RUN_ROAD_ONLY.m
只看機車路線：01_執行入口/SHOW_MOTORCYCLE_PATHS.m

整個資料夾請一起搬移或分享，不要只傳單一程式檔。
